Tarefa — Landing Page + Lead Magnet
 
Criar uma campanha integrada de captação de leads, articulando a Landing Page, o Lead Magnet e a sequência de emails já desenvolvida.
1. Landing Page
Criar uma landing page destinada à captação de contactos, que deve incluir:
Título e proposta de valor;
Apresentação do problema/necessidade;
Benefícios da oferta;
Apresentação do Lead Magnet;
Formulário de recolha de dados;
Call-to-Action (CTA);
Elementos de confiança (testemunhos, garantia, dados, etc.).
2. Lead Magnet
Criar um recurso gratuito que seja relevante para o público-alvo, por exemplo:
Ebook;
Checklist;
Guia;
Template;
Infográfico;
Mini-curso.
O Lead Magnet deve resolver um problema concreto e justificar a entrega do contacto.
